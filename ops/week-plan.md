## Facts for this week

The workers can't search the web. Use only the facts here, in ops/growth-brief.md and in the code. Never name a competitor site in copy.

Remux facts (MKV, checked 11-25-2026):
- An MKV holds a track list (video, audio, subtitles) and then the data in "clusters" of a few seconds each. Adding or removing a subtitle track rewrites the track list and the subtitle lines. The video and audio bytes are copied as they are, so nothing is re-encoded and the picture and sound don't change.
- Saving: in Chrome and Edge on a computer the page writes the new file straight to disk, piece by piece (`showSaveFilePicker`). Other browsers (Firefox, Safari, phones) build one download link from pieces of the original file. Very large files may fail there; tell the reader to use Chrome or Edge on a computer for big films. Don't promise a size for those browsers.
- SRT and WebVTT files go in as SRT text (Matroska codec `S_TEXT/UTF8`), which most players and many TVs read. ASS and SSA keep their styles (`S_TEXT/ASS`, `S_TEXT/SSA`), but some TVs skip styled tracks.
- The default flag tells the player which subtitle track to turn on when the viewer hasn't chosen. Players with their own language setting can ignore it: VLC (Preferences, Subtitles / OSD, Preferred subtitle language), Plex (account language settings, subtitle mode), Jellyfin (user settings, subtitle mode).
- A forced track is meant for foreign-language lines and signs only; many players show forced tracks even when subtitles are off.
- The desktop routes, for guides only: the free MKVToolNix, `mkvmerge -o out.mkv movie.mkv --language 0:spa movie.spa.srt` adds a track; `mkvmerge -o out.mkv --subtitle-tracks 3 movie.mkv` keeps only subtitle track 3; `--no-subtitles` drops all of them.
- Files this tool can't edit: files recorded as a live stream (sizes unknown, some browser and camera recordings), and files over 126 tracks. The page shows the error from the code.

## Writer spec (rows 2 and 3)

Matroska is EBML: every element is an ID (1 to 4 bytes, marker bit kept), a size (1 to 8 bytes, the first byte's leading zero bits give the length, the marker bit dropped; all value bits 1 = unknown size), then the body. src/lib/mkv.ts already reads this. In this spec "u64(n)" is 8 bytes big-endian, and a "fixed size" is the 8-byte form `0x01` followed by 7 bytes of the value.

1. Exports in src/lib/mkv.ts. Add `export` to `readVint`, `headerAt`, `children`, `uintOf`, `class Reader` and the `ID` const, and export `CHUNK`. No other change; `npm test` must still pass. New file src/lib/mkvwrite.ts imports them plus `parse` from './subs.ts'. Write local helpers there: `idBytes(id)` (as in test/mkv-fixture.ts), `sizeVint(n)` (smallest length L from 1 to 8 with `n < 2 ** (7 * L) - 1`; first byte `(1 << (8 - L)) | high bits`), `fixedSize(n)` (`0x01` + 7 bytes), `u64(n)`, `el(id, ...parts)` (id bytes, sizeVint of body, body), `uint(id, v)` (minimal bytes, at least 1), `str(id, s)` (UTF-8), `cat(...parts)`, and `elements(b: Uint8Array): { id: number; start: number; dataStart: number; end: number }[]`, which works like `children` but returns offsets, so raw child bytes can be copied with `b.subarray(start, end)`. Extra IDs: `SEEK_HEAD 0x114d9b74`, `SEEK 0x4dbb`, `SEEK_ID 0x53ab`, `SEEK_POSITION 0x53ac`, `VOID 0xec`, `CRC32 0xbf`, `CUES 0x1c53bb6b`, `CUE_POINT 0xbb`, `CUE_TIME 0xb3`, `CUE_TRACK_POSITIONS 0xb7`, `CUE_TRACK 0xf7`, `CUE_CLUSTER_POSITION 0xf1`, `CHAPTERS 0x1043a770`, `ATTACHMENTS 0x1941a469`, `TAGS 0x1254c367`, `TRACK_UID 0x73c5`, `FLAG_LACING 0x9c`, `POSITION 0xa7`, `PREV_SIZE 0xab`.
2. Types and small exports.
   - `export type Part = Uint8Array | { start: number; end: number };` (a range of the source file).
   - `export interface AddTrack { codec: 'S_TEXT/UTF8' | 'S_TEXT/ASS' | 'S_TEXT/SSA'; codecPrivate: string; cues: { start: number; end: number; text: string }[]; language: string; name: string; forced: boolean; isDefault: boolean }` (times in ms; for ASS and SSA, `text` is the Matroska block payload).
   - `export interface EditOptions { add: AddTrack[]; remove: number[]; defaultExisting?: number | 'none' }`.
   - `export const LANGS: [string, string, string][]`: `['eng','en','English'], ['spa','es','Spanish'], ['fre','fr','French'], ['ger','de','German'], ['ita','it','Italian'], ['por','pt','Portuguese'], ['dut','nl','Dutch'], ['rus','ru','Russian'], ['pol','pl','Polish'], ['tur','tr','Turkish'], ['swe','sv','Swedish'], ['nor','no','Norwegian'], ['dan','da','Danish'], ['fin','fi','Finnish'], ['gre','el','Greek'], ['heb','he','Hebrew'], ['ara','ar','Arabic'], ['hin','hi','Hindi'], ['jpn','ja','Japanese'], ['kor','ko','Korean'], ['chi','zh','Chinese'], ['cze','cs','Czech'], ['hun','hu','Hungarian'], ['rum','ro','Romanian'], ['ukr','uk','Ukrainian'], ['vie','vi','Vietnamese'], ['tha','th','Thai'], ['ind','id','Indonesian'], ['und','','Undetermined']`.
   - `export function guessLanguage(fileName: string): string`: split the lowercased name on '.', drop the extension, look from the end for a part equal to a 3-letter or 2-letter code in LANGS (also accept 'fra' and 'deu'), return the 3-letter code, else 'und'.
   - `export function textTrack(text: string, fileName: string): Pick<AddTrack, 'codec' | 'codecPrivate' | 'cues'>`. If the text starts (after a BOM and spaces) with `[Script Info]`: codec `S_TEXT/SSA` if the header has `ScriptType: v4.00` without a `+`, else `S_TEXT/ASS`; `codecPrivate` = every line before the first `Dialogue:` line, joined with '\n', trailing space trimmed, plus '\n'; each `Dialogue:` line: take the text after `Dialogue:`, trim the start, split on the first 9 commas into Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text; times `H:MM:SS.cc` to ms; `text` = `${readOrder},${Layer},${Style},${Name},${MarginL},${MarginR},${MarginV},${Effect},${Text}` with readOrder counting 0, 1, 2 in file order. Otherwise `parse(text, 23.976, { name: fileName }).captions`, codec `S_TEXT/UTF8`, codecPrivate ''. No cues: throw `new Error('No subtitle lines found in ' + fileName + '.')`.
3. `export async function listTracks(src: MkvSource): Promise<{ number: number; type: number; codec: string; language: string; name: string; isDefault: boolean; forced: boolean }[]>`. Check the EBML magic as scanMkv does (same error text 'This is not an MKV or WebM file.'), walk level-1 elements inside the Segment with `Reader`, read the Tracks body once found, stop at the first Cluster. Parse every TrackEntry: number 0xd7, type 0x83, codec 0x86, language 0x22b59c (default 'eng'), name 0x536e, FlagDefault 0x88 (missing = true, the Matroska default), FlagForced 0x55aa. The page uses this to list tracks without reading the whole film.
4. `export async function editMkv(src: MkvSource, opts: EditOptions, onProgress?: (done: number, total: number) => void, signal?: AbortSignal): Promise<{ parts: Part[]; size: number; numbers: number[] }>`. `numbers` are the track numbers given to `opts.add`, in order. Pass 1 walks the file; pass 2 lays out the new file. Only Tracks, Cues, Info and the 12-to-16-byte headers are read; never a block body.
   Pass 1:
   - EBML header: the first element; keep the source range `[0, its end)`.
   - Segment: the next element must have ID `ID.SEGMENT`, else throw 'This MKV has no Segment.' `oldSegData` = its dataStart; `segEnd` = file size if its size is unknown, else dataStart + size. Bytes after segEnd are dropped.
   - Walk level-1 elements from oldSegData to segEnd (read 12 bytes with `Reader.get`, `headerAt`). Every 1 MB of position: `signal?.throwIfAborted()` and `onProgress?.(pos, src.size)`. Any element of unknown size: throw `new Error('This file was saved while it was being recorded, so its parts have no stated size. This page cannot edit it.')`. By ID:
     - SEEK_HEAD, VOID, CRC32: drop.
     - INFO: read the body, take TimestampScale (`scale`, default 1000000), keep as `{ kind: 'copy', id, start, end }`.
     - TRACKS: size over 1 MB: throw 'This MKV track list is damaged.' Read the body; keep as `{ kind: 'tracks', body }`. Validate `opts.remove` now (step 2 adds that).
     - CUES: size over 64 MB: drop it. Else read the body; keep as `{ kind: 'cues', body }`.
     - CLUSTER: a cluster before TRACKS: throw 'This MKV layout is not supported.' Walk its children (next bullet); keep as `{ kind: 'cluster', oldRel: pos - oldSegData, ts, ranges, tsEnd }`.
     - anything else (Chapters, Attachments, Tags, unknown IDs): keep as `{ kind: 'copy', id, start: pos, end }`.
   - Cluster children, from dataStart to end: read 16 bytes and `headerAt`; a child of unknown size or ending past the cluster end: throw 'This MKV is damaged.' Keep a child by adding `[start, end)` to `ranges` (extend the last range when it ends exactly at start). TIMESTAMP: `ts = uintOf(body)`, keep, `tsEnd = child end`. CRC32, POSITION, PREV_SIZE: drop (they would be wrong after editing). SIMPLE_BLOCK: read 8 bytes at dataStart, track = `readVint(b, 0, false).value`; drop if `remove` has it, else keep. BLOCK_GROUP: read up to 32 bytes at dataStart, find the BLOCK (0xa1) child header in them as scanMkv does, track from its first vint; drop if `remove` has it, else keep (also keep if no Block is found in 32 bytes). Others: keep. No Timestamp: throw 'This MKV is damaged.'
   - No TRACKS: throw 'This MKV has no track list.' No clusters: throw 'This MKV has no video or audio data.'
5. Pass 2, the new file.
   - Tracks: walk `elements(body)`. Keep only TrackEntry (0xae) children; drop CRC32 and Void. For each entry read number, type, uid from its children. Removed entries are skipped. If `rewriteDefaults` (some added track has `isDefault`, or `defaultExisting` is set) and type is 17: write `el(0xae, ...every child's raw bytes except FlagDefault, uint(0x88, number === defaultExisting ? 1 : 0))`; otherwise copy the entry's raw bytes. Added track i: `number = maxExisting + 1 + i` (throw 'This MKV has too many tracks.' above 126, so the block's track vint is 1 byte, `0x80 | number`); `uid` = `0x53460000 + number`, plus 1 until no existing uid equals it. Entry: `el(0xae, uint(0xd7, n), uint(0x73c5, uid), uint(0x83, 17), uint(0x88, isDefault ? 1 : 0), uint(0x55aa, forced ? 1 : 0), uint(0x9c, 0), str(0x86, codec), str(0x22b59c, language), name ? str(0x536e, name) : nothing, codecPrivate ? str(0x63a2, codecPrivate) : nothing)`. Always write FlagDefault: a missing FlagDefault means "default" in Matroska. New Tracks = `el(ID.TRACKS, ...entries)`.
   - Blocks: for each added cue, `t = Math.round(start * 1e6 / scale)`, `d = Math.max(1, Math.round((end - start) * 1e6 / scale))`, payload = UTF-8 of `text`. Sort all added cues (all tracks) by t. Cluster `i` for a cue = the last cluster with `ts <= t` (binary search over clusters in file order; none: 0). `rel = t - ts[i]`. If `-32768 <= rel <= 32767`, the block goes into cluster i's `adds`. Else it goes into an extra cluster after cluster i: reuse the last extra one after i when `t - extra.ts <= 32767`, otherwise start a new extra with `ts = t`. Block bytes: `el(0xa0, el(0xa1, [0x80 | n, (r >> 8) & 0xff, r & 0xff, 0x00], payload), uint(0x9b, d))` with `r = rel < 0 ? rel + 0x10000 : rel`. An extra cluster is `el(ID.CLUSTER, uint(0xe7, ts), ...its blocks)`.
   - Cues (build twice with `buildCues(posOf)`: once with `() => 0` for the size, then with real positions; the size is the same because positions are always u64): for each CuePoint (0xbb) in the old body, for each CueTrackPositions (0xb7): read CueTrack (0xf7) and CueClusterPosition (0xf1); keep it if the track isn't removed and a cluster has `oldRel === position`; write `el(0xb7, uint(0xf7, track), el(0xf1, u64(posOf(position))))`. A CuePoint with at least one kept position is `el(0xbb, raw CueTime child bytes, ...kept)`. No CuePoints kept: write no Cues at all.
   - Sizes and positions (relative to the new segment data start, 0 = first byte of the SeekHead): the SeekHead has one Seek per first INFO, TRACKS, CHAPTERS, ATTACHMENTS, TAGS and Cues (if written): `el(0x4dbb, el(0x53ab, idBytes(id)), el(0x53ac, u64(pos)))`, inside `el(0x114d9b74, ...)`; build it twice like Cues. Then walk items in order from `offset = seekHeadSize`: copy = `end - start`; tracks = new Tracks length; cues = Cues size; cluster = 12 (4 ID bytes + fixedSize) + sum of ranges + sum of adds, its `newRel = offset` recorded before adding, then each of its extra clusters' lengths. Record each seek ID's position.
   - Parts, in order: `{ start: 0, end: ebmlEnd }`; `[0x18, 0x53, 0x80, 0x67, ...fixedSize(segmentBodySize)]`; SeekHead; then per item: copy → `{ start, end }`; tracks → bytes; cues → bytes; cluster → `[0x1f, 0x43, 0xb6, 0x75, ...fixedSize(body)]`, the ranges up to `tsEnd` (split the range that contains tsEnd), `cat(...adds)` if any, the ranges after `tsEnd`, then its extra clusters. Merge source ranges that touch. `size` = sum of part lengths.
